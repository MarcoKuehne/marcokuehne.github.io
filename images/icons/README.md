# Alien box icons

These local files replace fragile external image URLs in the box CSS.

- `definition-alien.svg`: **Smiley green alien mmm.svg**, LadyofHats, public domain, Wikimedia Commons.
- `challenge-alien.webp`: preview of **Smiley green alien cool.svg**, LadyofHats, public domain, Wikimedia Commons.
- `amazing-alien.webp`: preview of **Blue smiley of an alien.svg**, EinTisch, CC BY-SA 4.0, Wikimedia Commons.
- `dedicated-alien.webp`: preview of **Pink smiley of an alien.svg**, EinTisch, CC BY-SA 4.0, Wikimedia Commons.
- `reading-alien.webp`: preview of **Yellow smiley of an alien.svg**, EinTisch, CC BY-SA 4.0, Wikimedia Commons.

The WebP files are unmodified renderings served by Wikimedia's thumbnail service.
